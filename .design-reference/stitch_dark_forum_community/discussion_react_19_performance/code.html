Comment optimiser les performances de rendu sur React 19 ?

Depuis la migration de notre application d'analyse temps réel vers React 19 RC, nous constatons des saccades lors de filtrages intensifs sur des listes de plus de 10 000 éléments avec graphiques SVG synchronisés.

J'ai expérimenté une séparation entre le thread principal et les mises à jour non bloquantes. Voici le scénario comparatif entre useTransition et useDeferredValue :

DataTableFilter.tsx 
const [isPending, startTransition] = useTransition();
const deferredQuery = useDeferredValue(searchQuery);

// Déclenchement non bloquant de la refactorisation
function handleQueryChange(e: ChangeEvent) {
  startTransition(async () => {
    await syncMetricsTelemetry();
    setFilterState(e.target.value);
  });
}

Temps de blocage (TBT) 340ms → 42ms

Est-ce que le compilateur React 19 rend l'usage systématique de memoization obsolète dans ce cas précis ?

Oui, avec le React Compiler (Forget), tu n'as plus besoin d'enrober manuellement avec useMemo ou useCallback. Le compilateur génère automatiquement un mémoïsation granulaire au niveau AST.

Pour ton cas, privilégie résolument useDeferredValue couplé à la prop initialValue :

const deferredList = useDeferredValue(data, []);
// Rendu immédiat du fallback sans gel UI
